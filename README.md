# Terminal Automation Suite Version 1.2

An enterprise-grade test automation and interactive remote execution desktop application built with Python, PyQt6, and Paramiko. The suite provides a dual-console environment for running sequential, regex-validated test scripts from CSV templates, interacting directly with remote terminals by SSH, and batch-executing test suites with automated pass/fail log persistence.

## Core Capabilities

### 1. Dual-Console Operations

* **Console 1 (Orchestration Engine)**: Tracks execution state in real time, displays timestamps, logs command dispatch, validates target regular expressions, and reports individual step verdicts (`PASS`, `FAIL`, `TIMEOUT`).
* **Console 2 (Interactive Terminal)**: Connects directly to the remote server shell via Paramiko (VT100/Xterm). Supports full duplex bidirectional keyboard entry, cursor movements, and standard escape commands.

### 2. Native Terminal Parsing Engine

* **Screen Clear Handling**: Automatically intercepts terminal control sequences (such as `clear`, `\x1b[2J`, `\x1b[3J`) and clears Console 2 dynamically without artifacts.
* **ANSI & Bell Stripping**: Discards OSC window titles (`\x1b]0;...\x07`), terminal control codes, and ASCII Bell bytes (`\x07`), eliminating prompt noise and `` symbols.
* **Control Character Translation**: Translates control strings such as `'Ctrl+]'` into raw byte sequences (`\x1d`) for interacting with nested telnet and serial sessions.

### 3. CSV Sequence Execution

* Execute the entire sequence or only highlighted/selected rows.
* Click outside the table rows or press `Esc` to instantly clear row selection.
* Optional **Stop execution on failure** failsafe prevents accidental local script execution when a remote step breaks.

### 4. Independent Stream Logging

* Start, stop, or pause logging independently on Console 1 and Console 2.
* Toggle buttons open a save-file dialog; output writes directly to disk in append mode.

### 5. Auto Batch Runner

* Dedicated batch modal launched via the **Auto** button.
* Drag and drop multiple `.csv` files into the queue or add them using a file browser.
* Evaluates suites strictly: if a single step within a CSV fails, the entire template is flagged as `FAIL`.
* Tracks execution time per file with a live elapsed-timer column.
* Automatically creates separate, sanitized log files labeled with the execution status:
* `<load_file_name>_console_1_<pass|fail>.txt`
* `<load_file_name>_console_2_<pass|fail>.txt`

## CSV Template Schema

Test sequences are imported and exported as standard UTF-8 CSV files with no mandatory headers. Each row represents a distinct command phase:

| Column Index | Field Name | Type | Description | Example |
| --- | --- | --- | --- | --- |
| **0** | `Command` | String | Terminal command or control sequence | `telnet 192.168.1.2 4003` |
| **1** | `Timeout (s)` | Numeric | Maximum time to wait for expect pattern | `10` |
| **2** | `Expect (Regex)` | String | Case-insensitive regular expression pattern | `Connected to |
| **3** | `Status` | String | Execution feedback (*Queued, Running, PASS, FAIL*) | *(Auto-generated by runner)* |

### Example CSV Data

```csv
telnet 192.168.1.2 4003,10,Escape character,Ready
stress-ng --cpu 12 --timeout 10m --metrics-brief,610,successful run completed,Ready
'Ctrl+]',5,telnet>,Ready
q,5,Connection closed,Ready

```

## Keyboard Shortcuts & Navigation

| Context | Shortcut | Action |
| --- | --- | --- |
| **Console 1 & 2** | `Ctrl` + `Mouse Wheel` | Zoom in / Zoom out font size |
| **Console 1 & 2** | `Ctrl` + `+` / `Ctrl` + `-` | Increment or decrement font size |
| **Console 1 & 2** | `Ctrl` + `0` | Reset font to default (10 pt) |
| **Console 2** | `Ctrl` + `Shift` + `C` | Copy selected terminal text |
| **Console 2** | `Ctrl` + `Shift` + `V` | Paste text into remote terminal session |
| **Console 2** | `Tab` | Remote autocomplete (passes directly to remote shell) |
| **Console 2** | `Ctrl` + `C` | Interrupt current process (`SIGINT`) |
| **Command Table** | `Esc` | Clear row selection (resets to "Run All" mode) |
